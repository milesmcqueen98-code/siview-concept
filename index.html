How this page answers the RFP

Numbers match the markers on the page. Q numbers refer to the District's answers to proposers' questions.

  1. 1Alert bar staff control

    Replaces the custom urgent-message database (Q3). Staff write the message, add a link and set start and end dates in WordPress.

  2. 2Register goes to Dash

    Every Register button opens the right Dash page, so today's external links remain the minimum (Q5). Buttons have text labels; today's header uses unlabeled icons (WCAG 1.1.1).

  3. 3Menus that work by keyboard

    Menus open by click, tap, Enter or Space, close with Escape, and announce whether they are open. Today they open only on mouse hover (WCAG 2.1.1, 4.1.2). Staff can reorder them each season (Q27).

  4. 4Today's pool times

    Pulled from the same table as the Pool Schedule page, so staff edit one schedule and both pages stay in step.

  5. 5No slider

    Today's four slider promotions become real text in a fixed grid: no motion and no pictures of text (WCAG 2.2.2, 1.4.5). Staff swap them each season without a webmaster (Q18).

  6. 6One record per event

    Each event is entered once and feeds this list, its own page and the calendar, and drops off after it ends. Today the Spooktacular's non-resident price is $20 on its page and in Dash, but $21.60 on the Family FUN page.

  7. 7E-News sign-up

    A labeled field that checks the address before it sends, connected to Constant Contact (Q20). Today's field has no label (WCAG 1.3.1, 3.3.2).

  8. 8A light page

    Photos are sized for each screen and load as you scroll. With every photo loaded, this page is about 1 MB; today's homepage loads about 4.6 MB.
